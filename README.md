# AlgorithmsAndDataStructures
This repository contains implementations of basic data structures and algorithms, completed during the practical sessions of the "Theory of Algorithms" course in the first year of study at NURE.

## Tech Stack
Language:Python

## Repository Structure

The project includes the following scripts, covering various algorithmic concepts:

`branching.py` — Basic algorithms and branching structures.
`cyclic.py` — Cyclic algorithms, input validation, and series sum calculations.
`arrays.py` & `1arrays.py` — Processing and manipulating 1D arrays (finding minimums, replacing elements, etc.).
matrices.py` — Operations on 2D arrays (matrices), including index-based calculations.
`sorting.py` — Implementation of classic sorting algorithms: Cocktail Sort, Counting Sort, and Selection Sort.
`search.py` — Linear search algorithm optimized with the transposition method, including search statistics.
`dijkstra.py` — Implementation of Dijkstra's algorithm for finding the shortest paths in a graph.

## How to Run

To test any of the algorithms, simply run the corresponding script using Python 3. For example:
```bash
python dijkstra.py
